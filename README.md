# SGS Support

แอปเดสก์ท็อป Rust + Dioxus 0.7 สำหรับช่วยนำคะแนนจาก Excel ไปกรอกในระบบ SGS โดยจับคู่ข้อมูลด้วย `stdID` ก่อนกรอกทุกครั้ง

## ความสามารถ

- เปิด Chrome หรือ Edge และเข้าสู่ระบบ SGS จริง
- สลับไปใช้ mockup ที่ `http://localhost/sgs_tester/` สำหรับทดสอบ
- อ่าน `.xlsx`/`.xlsm` หลายชีต โดยถือว่าแต่ละชีตเป็นหนึ่งห้องเรียน
- ดาวน์โหลดไฟล์ตัวอย่าง `sgs-all.xlsx` จากปุ่มสีเขียวด้านบน โดยไม่ต้องมีโฟลเดอร์ `assets` อยู่ข้างไฟล์โปรแกรม
- รองรับคะแนนก่อนกลางภาค `S1`–`S9`, `Midterm`
- รองรับคะแนนหลังกลางภาค `S10`–`S18`, `Final`
- รองรับคุณลักษณะ `Q1`–`Q8` และการอ่านคิดวิเคราะห์ `L1`–`L5`
- ไม่กดบันทึกเมื่อไม่พบรหัสนักเรียนตรงกัน ไม่มีคะแนนสำหรับหน้านั้น หรือกรอกบางช่องล้มเหลว

## รูปแบบ Excel

สองคอลัมน์แรกต้องเป็น:

```text
stdID | student Name | S1 | ... | Midterm | S10 | ... | Final | Q1 | ... | Q8 | L1 | ... | L5
```

คอลัมน์คะแนนที่ไม่มีในไฟล์หรือเซลล์ว่างจะถูกข้าม จึงใช้ไฟล์แบบย่อที่มีเฉพาะคะแนนที่ต้องการกรอกได้

หากยังไม่มีไฟล์ ให้กด `โหลดไฟล์ตัวอย่าง` ที่แถบด้านบน แล้วเลือกตำแหน่งบันทึก ไฟล์ตัวอย่างมีหัวตารางสองชีตและยังไม่มีข้อมูลนักเรียน สามารถคัดลอกไปกรอกข้อมูลจริงก่อนนำเข้าโปรแกรมได้

## วิธีใช้งาน

1. รันแอปและเลือก `SGS จริง` หรือ `Mockup localhost`
2. กรอกชื่อผู้ใช้/รหัสผ่าน แล้วกดเปิดเบราว์เซอร์
3. เลือกไฟล์ Excel
4. เลือกประเภทคะแนน แล้วกด `เปิดหน้า SGS`
5. ในหน้าต่างเบราว์เซอร์ เลือกปีการศึกษา ชั้น ห้อง และรายวิชาให้ถูกต้อง
6. กลับมาที่แอป แล้วกด `กรอกและบันทึกหน้านี้`

โปรแกรมไม่บันทึกรหัสผ่านเป็นไฟล์ข้อความ และจะรวมรายชื่อนักเรียนจากทุกชีตเพื่อจับคู่เฉพาะรายชื่อที่แสดงในหน้า SGS ปัจจุบัน

เมื่อเข้าสู่ระบบ SGS จริง โปรแกรมจะตรวจว่าหน้าแรกแสดงสถานะเข้าระบบแล้ว หาก SGS แสดงข้อผิดพลาดของเซิร์ฟเวอร์ชั่วคราว โปรแกรมจะโหลดหน้าแรกใหม่ไม่เกินสองครั้งก่อนแจ้งปัญหา

ทุกครั้งที่เปิดเบราว์เซอร์ โปรแกรมจะใช้โปรไฟล์ชั่วคราวแยกจากรอบก่อน จึงไม่เผลอใช้บัญชีที่เคยเข้าสู่ระบบค้างไว้ และจะลบโปรไฟล์นี้เมื่อปิดเบราว์เซอร์ผ่านโปรแกรมตามปกติ

หากต้องการให้โปรแกรมเติมชื่อผู้ใช้และรหัสผ่านในครั้งถัดไป ให้ติ๊ก “จำรหัสผ่านใน Windows เครื่องนี้” ก่อนเข้าสู่ระบบสำเร็จ ข้อมูลจะเก็บใน Windows Credential Manager ของบัญชี Windows ปัจจุบัน ไม่อยู่ในไฟล์โปรเจกต์ เอาเครื่องหมายออกเพื่อลบข้อมูลที่จำไว้ ปุ่ม “ออกจากระบบ” บนหน้ากรอกข้อมูลจะออกจากเว็บ SGS และปิดเบราว์เซอร์ แต่ยังคงรหัสผ่านที่เลือกให้จำไว้จนกว่าจะเอาเครื่องหมายออก

## การแสดงผล

หน้าตาของแอปใช้ CSS ปกติใน `assets/main.css` ไม่ได้ใช้ Tailwind แม้จะมีไฟล์ Tailwind ที่เหลือจากโปรเจกต์เริ่มต้นอยู่ก็ตาม CSS หลักถูกฝังในโปรแกรมเพื่อให้ `cargo run` แสดงผลได้ทันที โดยไม่ต้องใช้ Dioxus CLI (`dx`) เพื่อ bundle asset ก่อน

หน้าต่างเริ่มต้นมีขนาด 680×680 โดยยังคงความกว้างกะทัดรัดไว้ แต่เพิ่มความสูงของช่องสถานะ ซึ่งจะขยายตามความสูงหน้าต่างได้ เมื่อเปิด Chrome/Edge สามารถปรับขนาดหรือขยายเต็มจอได้ โดยพื้นที่แสดงหน้าเว็บจะปรับตามหน้าต่างเบราว์เซอร์

## พัฒนาและทดสอบ

```powershell
cargo run
cargo test --all-features
cargo clippy --all-targets --all-features -- -D warnings
```

สร้างไฟล์ release:

```powershell
cargo build --release
```

ไฟล์ `target/release/sgs_support.exe` เป็นแอป GUI บน Windows จึงไม่เปิดหน้าต่างคอนโซลเมื่อดับเบิลคลิก ส่วน debug build ยังคงมีคอนโซลไว้ช่วยตรวจข้อผิดพลาด
ไฟล์ตัวอย่าง Excel และ CSS หลักถูกฝังไว้ใน `.exe` ที่คอมไพล์แล้ว จึงไม่ต้องคัดลอกโฟลเดอร์ `assets` ไปด้วย
